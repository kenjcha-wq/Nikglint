# GLINT · 万物集

## 产品定位

**GLINT · 万物集** 是一个**人生流水记录系统**。

它不是日记应用，不是社交应用，不是照片收藏应用。它是一个帮助你**低成本记录人生中发生过的人、事、物、地点、想法和身体变化**的私人档案工具。

**核心价值：** 记录人生轨迹，而非表达情绪。

---

## 与其他产品的边界

| 产品 | 定位 | 与 GLINT 的区别 |
|------|------|----------------|
| **他我笔记** | 写文章、日记、回忆、情绪表达，支持图片上传 | GLINT 不写长文，不上传图片，只做快速片段记录 |
| **知识库** | 资料和知识管理 | GLINT 不管理知识，只管理人生流水 |
| **社交应用** | 分享、互动、社区 | GLINT 完全私人，无社交功能 |
| **照片应用** | 图片存储与管理 | GLINT 不保存图片，纯文本记录 |

## 功能模块

### 01 记录
快速捕获人生片段，无需思考"写什么"。

**六个分类维度：**

| 分类 | 记录内容 | 引导问句 |
|------|----------|----------|
| 目之所见 | 看到的人、景、环境、变化 | 今天看到了什么？ |
| 耳之所闻 | 听到的信息、对话、声音、消息 | 今天听到了什么？ |
| 身之所感 | 身体状态、感受、体验 | 今天身体有什么变化？ |
| 心之所想 | 想法、灵感、计划、念头 | 今天有什么念头？ |
| 世间所遇 | 遇见的人、发生的事情、关系变化 | 今天遇到了谁或什么事？ |
| 手中所藏 | 拥有的物品、购买、收藏、留下的东西 | 今天有什么东西值得留下？ |

**交互方式：**
- 点击分类切换记录类型，输入框自动显示对应的引导问句
- 支持快捷键 `⌘+↵` 快速存档
- 实时字数统计

### 02 时间线
按时间倒序展示所有记录，支持过滤和搜索。

**过滤：** 可按六个分类筛选查看
**搜索：** 全文搜索所有记录内容
**视觉：** 每条记录旁显示对应的分类图标（极简线稿），方便快速扫视

### 03 映射
自动分析记录的分布结构，生成统计与洞察。

**统计维度：**
- 总记录数 / 今日记录数
- 分类占比分布
- 日 / 周 / 月 时段切换

**智能洞察：**
- 记录密度评估
- 主导流向识别（外部感知 / 内在觉察）
- 最近记录预览

### AI 助手
不是聊天机器人，而是**人生档案整理助理**。

- 基于你的记录进行对话式查询
- 帮助总结近期状态
- 发现人生轨迹中的变化

## 设计理念

### 极简 · 克制 · 档案馆气质

- 冷灰主色调，暖色点缀
- 细边框、米白背景
- 无冗余视觉干扰
- 像翻阅个人档案一样安静

### 引导式记录

用户打开应用后，不需要思考"我要写什么"：

> **今天，留下什么？**

下方提供六个明确的记录方向，每个方向都有具体的引导问句，降低记录的心理门槛。

### 无图片 · 无社交 · 无情绪

GLINT 只记录**事实片段**，不鼓励情绪宣泄或图片收藏。它是你人生的**流水账本**，不是你的**心情日记**。

---

## 技术特性

- **纯前端应用**：单 HTML 文件，开箱即用
- **本地存储**：数据保存在浏览器 localStorage
- **云端同步**：可选配置 Supabase，实现多设备同步
- **数据导出/导入**：支持 JSON 格式的完整数据迁移
- **隐私优先**：所有配置和数据默认存储在本地

---

## 视觉风格

- 字体：系统字体 + SF Mono（代码/数字）
- 配色：冷灰背景 + 暖色点缀（琥珀金）
- 图标：极简 SVG 线稿，单色，不喧宾夺主
- 墙纸：支持点阵、纯白、暖白、暗色、纸纹、网格、自定义图片

---

## 适用场景

- 想记录但不想写长文的人
- 想留存人生轨迹但不想被情绪裹挟的人
- 追求极简、克制的数字生活的人
- 想回顾"某年某月我在做什么"的人
